# Grey Hack Tools by Hobo & Rowan

GreyScript utilities and Auto Family automation for **Grey Hack Public v0.9.6773**. These programs operate only through Grey Hack's fictional in-game systems and APIs.

Every tool has its own folder with its newest source, installation notes, commands, release notes, storage paths, and honest runtime boundaries. Git history preserves older revisions; the visible repository remains a current-release shelf rather than a pile of superseded builds.

## The Auto Family

The tools are siblings rather than clones: each has one job, while compatible members share organized runtime data beneath `/root/autoscripts/` and exact-version exploit knowledge through `/root/vulndb`. AutoRoute provides the trusted route, AutoNet supplies optional proxy nodes, AutoRecon grows the shared knowledge base, and mission workers reuse that knowledge while handling their own target workflow and cleanup.

## Installation

Open the selected `.src` in Grey Hack's `CodeEditor.exe`, compile it to the command documented in that tool's README, and place the compiled command in `/bin`. A release-candidate suffix is an honest field-test boundary, not an obsolete build. Dependencies and any public configuration blanks are documented per tool.
