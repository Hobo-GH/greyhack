# AutoRecon

This public release contains the complete AutoRecon `2.2.1` source with private configuration left blank.

Version `2.2.1` preserves the `2.2.0` engine and corrects only controlled terminal presentation: color-tag defaults, ACLOG event classification, overlooked semantic values, and mixed server identity/network coloring.

- `PIN` is blank and must be configured before personal use.
- Server B IP and SSH password are blank.
- Compile `autorecon-2.2.1.src` as `/bin/autorecon`.
- Keep personal credentials out of this lane.

The `2.2.0` database download, upload, synchronization, cleanup, and coverage-export lifecycle was field-confirmed. Version `2.2.1` preserves that engine and packages the presentation correction for the coordinated Auto Family release.
